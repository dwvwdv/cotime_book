# 版本歷史

格式：`### vX.X.X+N (YYYY-MM-DD)`，最新的在最上面。每一項用 emoji 前綴標示類型：
✨ 新功能 / 🐛 修復 / 🎨 UI / ⚡ 優化（含依賴升級、CI、內部重構）。

- 寫給**之後要彙整發版說明的人**看：講使用者看得到的變化，再補一句為什麼。
  protocol 代碼與檔名可以出現，但不要整段只剩識別字。
- 對應 GitHub issue 時標出編號（`#31`），細節留在 issue 與 PR，不要兩邊各寫一份。
  既有條目裡的 `issue #21`、`issue #U` 是已移除的 `issue.md` 的舊編號（見 `CLAUDE.md`）。
- 同一個 PR 只有一個版本條目（見 `version-update.md`）；review 修復追加在同一條目下。
- 只動文件、`.claude/`、`.github/` 的 PR 不 bump 版號，不必新增條目。

### v1.0.12+16 (2026-10-24)

- ✨ 公共圖書館改讀 pCloud 公開資料夾：維護者把 EPUB 丟進資料夾就上架，不再受 Supabase Storage 1GB 的限制。超過 40MB 的書仍不列出。需要先套 `20261024054844_library_public_folder.sql` 再發版；舊版 App 仍讀原本的 Storage bucket。
- ✨ 圖書館改用 tags 分類，一本書可以有多個 tag，篩選時可以同時選多個 tag（只留下全部符合的書），最常用的 tag 排在前面；書名改成中文，原文書名與作者也搜得到；每本書都標上書本身的語言，封面左上角直接顯示「En」「Zh」。資料夾裡現有的 48 本古騰堡計畫書籍都已建好目錄。
- ✨ 圖書館標題旁的說明按鈕會顯示資料夾裡的「書籍來源聲明.txt」，維護者改這個檔案就能更新說明。

### v1.0.11+15 (2026-10-23)

- ✨ TXT 轉 EPUB 改成首頁左下角的獨立工具「TXT to EPUB」：選檔、確認編碼與章節後轉成 EPUB，可以先在本機打開閱讀（有目錄，排版與房間相同）確認沒問題，再「Save EPUB」存到裝置。以前是在房間裡直接轉換並分享，轉壞了要整個房間一起等、一起換書。
- ⚡ 房間的「Share Book」只收 EPUB；選到 TXT 會提示先到首頁轉換。傳書、閱讀與儲存都不再碰 TXT。

### v1.0.10+14 (2026-10-23)

- ✨ 房間的字級預設由房主決定：其他人的字級按鈕會停用並說明「由房主設定」，房主可以在閱讀設定裡關掉「Only I set the text size」，大家再各自調整（房間仍以最大的字級排版）。以前任何一人調大字，全房都要等重新排版。需要先套 `20261023120000_room_text_size.sql` 再發版。
- ✨ Page Layout Report 可以直接送出（#49）：按「Send Report」存進資料庫並拿到報告 ID，不必再複製貼上；報告多了 App 版本、裝置、書、房內每個 reader 的頁框與最近幾次翻頁的紀錄，同一房間的報告可以互相對照。需要 `20261023120001_layout_reports.sql`。
- 🎨 閱讀畫面進入閱讀設定的按鈕改成設定圖示；字級區塊提醒新的字級要幾秒才會出現，避免連按。

### v1.0.9+13 (2026-10-23)

- 🐛 有些書（calibre 從 GitBook 轉出的 EPUB 等）每一章只顯示一頁、頁底被切掉，翻一頁就跳到下一章（#49）：書把整章包在 `overflow: hidden` 的容器裡，這種容器沒辦法分到多頁，整章被擠進一頁、其餘被裁掉。共享排版現在讓書裡的元素一律不裁切，章節照常分頁。同一房間的裝置要都更新到這一版，含這類容器的書分頁才會一致：房間協定版本因此升到 2，1.0.8 以前的成員會在 lobby 與閱讀畫面標示「需要更新 App」，翻頁逾時也會說明是誰要更新。

### v1.0.8+12 (2026-10-23)

- 🐛 書裡有不能斷行的長網址時，網址被切在頁緣，下一頁還會被命名成網址溢出的那個字，大家被帶回上一頁、整房卡在同一頁翻不過去（#52）：過長的字串與程式碼改在欄內換行，頁首也只認「從這一頁開始的那一行」。
- 🐛 閱讀時頁面底部被切掉、翻一頁跳過大段內容（#49）：每次套用共享頁面都強制 epub.js 重新排版，並在翻頁或顯示停下後確認書確實排在畫面上的頁框裡，不一致就自動重排一次。實機上的根因還沒確認，所以同時加了回報工具（見下一條）。
- ✨ 閱讀設定多了「Page Layout Report」：一鍵複製這台裝置的排版狀態（頁框、縮放、每章的排版尺寸、上一次翻頁移動了幾頁），遇到切字或跳頁時貼進 #49。
- 🐛 平板放大頁面時，Android WebView 不再把頁面放在 980px 寬的「桌面版」版面上（#48）：縮放時明確指定版面寬度。
- 🎨 首頁的「頁間」改成印章：黑底白字直排在 CoTime Book 旁邊，不再是兩行搶位置的大標題。

### v1.0.7+11 (2026-10-23)

- ✨ App 的中文名稱定為「頁間」：中文系統的啟動器顯示「頁間」，其他語言仍是 CoTime Book；首頁標題同時列出兩個名字。
- ✨ 平板和手機一起讀時，平板不再顯示一頁手機大小的書加上大片空白：整頁（含文字）放大到填滿螢幕，每一頁的內容仍與其他人相同（#37）。放大用的是 WebView 的頁面縮放；若某台裝置的 WebView 不支援，會維持原本的置中顯示。
- 🐛 lobby 在矮螢幕（橫向手機、小尺寸電子閱讀器）上同時顯示傳書進度與書卡時不再溢出、按鈕不再被截掉：整頁改成可以捲動，放得下時按鈕仍在底部（#45）。
- 🐛 lobby 的傳書錯誤（例如圖書館下載失敗）不再一直掛著：20 秒後自動消失，也可以按 ✕ 關掉；重試就是再分享一次（#44）。
- ⚡ CI：PR 建置的 Telegram 通知不再把分支名稱直接內插進 shell；發 Release 的 action 升到 `action-gh-release@v2`（#46）。

### v1.0.6+10 (2026-10-22)

- 🐛 從圖書館分享書之後才進房間的成員，也會直接從圖書館下載，不再退回較慢的 P2P 傳輸（#28）。需要先套 `20261022120000_room_book_library_path.sql` 再發版；沒套之前只有分享圖書館的書會失敗，分享自己的檔案不受影響。
- 🐛 被移出房間（在別台裝置離開、閒置太久被移除、房間關閉）時，App 不再反覆嘗試連線，而是回到首頁並說明原因；heartbeat 發現已不在房內時也一樣自動回首頁（#36）。
- ✨ 房間成員的 App 版本與自己不相容時，lobby 與閱讀畫面會標示「需要更新 App」，翻頁逾時也會說明在等的人要更新（#33）。v1.0.5 與這一版相容，不會被標示。
- ✨ 閱讀主題、字級與音量鍵翻頁會記住，下次開 App 不用重設（#32）。
- 🐛 TXT 匯入：沒有 BOM 的中文 UTF-16 自動辨識；GBK 檔裡的 GB18030 罕用字不再變成 `�`；認得「一、」「【01】」這類章節標題（全書一致才採用），確認時可以關掉分章改依字數切段（#42）。
- 🐛 錯誤訊息不再被不相關的狀態更新順手清掉，開始新操作或成功時才清除（#30）。
- 🐛 按「離開」時剛好有 heartbeat 在路上，首頁不再顯示「membership expired」。
- ⚡ Realtime 頻道只接受房號 topic，移除沒用到的 channel_id 授權（#31，`20261022120001_room_topic_code_only.sql`）。
- ⚡ CI 在共享頁面相關檔案變動時跑 `tool/shared_page_check`（#39）；realtime 的計時測試改用 fake time，機器忙碌時不再偶發失敗（#40）。

### v1.0.5+9 (2026-10-21)

- ✨ 可以一起讀 TXT 小說：「Share Book」接受 TXT，可以一次選多個檔案（例如分卷的小說），依檔名順序合成一本書，在這台裝置上轉成 EPUB 再分享，其他人收到的就是一般的 EPUB，舊版 App 也讀得了（#27）。章節判斷與編碼的已知限制見 #42。
- ✨ 分享 TXT 前會先確認：書名、作者、每個檔案的編碼（自動偵測 UTF-8／UTF-16／GBK／Big5，預覽是亂碼時可以換）、章數與順序。
- ⚡ `tool/shared_page_check` 也檢查 TXT 轉出的書在兩台裝置上逐頁一致。

### v1.0.4+8 (2026-10-21)

- 🐛 翻頁後 requester 看到一整頁空白、其他人停在原地，要再翻一次才同步：章末空段落溢出的空白頁會被直接跳過；只有插圖的頁改用插圖命名，大家會落在同一頁（issue #22）。

### v1.0.3+7 (2026-10-05)

- ✨ 圖書館獨立成自己的元件：lobby 多一個「Library」按鈕，打開後是封面網格（只顯示書名），可以用書名或作者搜尋，分類與語言收在搜尋框旁的篩選按鈕裡；「Share Book」回到直接選這台裝置上的檔案（issue #AB）。
- ✨ 圖書館有了目錄：維護者在 `cotime_book.library_books` 填書名、作者、語言、分類，中文書名終於能顯示；還沒建目錄的書照樣列出，標題沿用檔名（issue #AA）。正式庫已套用 `20261005120000_library_catalog.sql`，並為現有 5 本書建好目錄。
- ✨ 圖書館的書有封面：目錄的 `cover_path` 指向 bucket 裡 `covers/` 的圖，沒有封面時顯示印著書名的素面書衣（`20261005130000_library_covers.sql`，正式庫已套用）。
- 🎨 lobby 的按鈕改成兩列：「Share Book / Library」並排，「Start Reading」在下方全寬。

### v1.0.2+6 (2026-10-04)

- ✨ 公共圖書館：lobby 的「Share Book」改成先選來源——這台裝置上的檔案，或圖書館裡的書。圖書館就是 Supabase Storage 的 `cotime-book-library` bucket，維護者把開源 EPUB 放進去，檔名就是書名；App 只能列出與下載。
- ⚡ 分享圖書館的書時不再經過 Realtime 逐塊廣播：收書端直接從 Storage 下載（以 hash 驗證），下載失敗或 60 秒內沒完成才改向房內的人要（issue #M 部分緩解）。
- ✨ 單本書的大小上限從 10MB 提高到 40MB。

### v1.0.1+5 (2026-10-02)

版號規則建立後的第一個版本，起點從 1.0.0+4 往上加。App 本身的行為沒有變。

- ⚡ 從無感記帳移入開發規範：版號與 changelog 規則（`version-update.md`、本檔）、構建與 CI 說明（`build-and-deploy.md`）、Codex review 門檻（`AGENTS.md`），以及雲端 session 自動安裝 Flutter 的 hook。
- ⚡ CI：只改 `assets/` 的 PR 現在也會觸發 Build Check（issue #W）；可手動觸發、同一個 PR 連續 push 時取消舊的 run、runner 可用變數設定、單一測試最多 2 分鐘、Telegram 通知加上逾時與下載連結備援；release 對只改文件的 push 不觸發；新增比對 keystore 指紋的 workflow。
